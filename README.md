# artelplast-assets

Публичные файлы для сайта artelplast-nsk.ru (GitHub Pages). Только медиа для сайта — никаких данных компании.

- `video/home-cover/` — видео-обложка главной (v6, 09.11.2026): `cover_<ширина>x<высота>.mp4` (H.264, без звука, 10,9 с) и постеры `poster_*.webp` (первый кадр). Исходники и сборка — в закрытом репозитории `artelplast-data`, `reports/site/video_cover/`.
- `video/chehol/` — ролик «Как надеть чехол на теплицу» (20.11.2026, 44 с, без звука, без цен): `chehol_720x1280.mp4`, `chehol_480x854.mp4` (медленный интернет), постер `poster_720x1280.webp`; квадрат для компьютера — `chehol_720x720.mp4`, `poster_720x720.webp`. Для карточек чехлов на сайте.
